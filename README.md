# WingFlow
### A mini, interactive computation fluid dynamics(CFD) software for iOS.
> Selected as a winner of the 2026 [Swift Student Challenge](https://developer.apple.com/swift-student-challenge/) by <b>Apple, Inc.</b>

## Features 
+ Choose an airfoil from a list of popular designs, including:
   + Trainer(based off Cessna 172)
   + Glider
   + Utiltiy(Based of STOL aircraft)
+ Create costom airfoils in the `Costom Wing Builder`
   + Manipulate camber, chord, and thickness
   + See changes update live
+ Use sliders to adjust:
   + Airspeed
   + Angle of attack
   + Partical density(adjust simulator load)
+ Watch lift/drag gauges update live
+ Click tooltips (?) to learn aerospace terms
